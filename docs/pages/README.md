# Design pages

HTML pages made during the design work, kept here so they can be regenerated and edited.

| File | What |
|---|---|
| `breadboard.html` | Two-node test rig on two half-size breadboards (camera node with the trigger nRF, and the PIR node), with wiring lists, bring-up order, and the bq24074 cell charger. Generated by `gen_breadboard.py` from `bb-style.css`; run `python3 gen_breadboard.py` in this folder to rebuild it |
| `carrier-concept.html` | Concept render of the combined rev B carrier board (XIAO nRF52840 + Wio-SX1262, camera XIAO, bq24074, MiniBoost, PIR on the back, IR gate). Written by hand. **Superseded by the two-node split**, kept as the design reference for the carrier boards |

Both were also published as private claude.ai artifacts while the design was being worked out (the carrier concept at
`claude.ai/artifact/FqtEsynA9CZGzDirLsoUuM`, the breadboard page at `claude.ai/artifact/UAuPhwgYjbRAAjyykL1vFe`); these
files are the source of truth. The pages load IBM Plex fonts from Google Fonts and work without them.

The pin orientation, module pin orders and the 0.6 inch XIAO row spacing in the drawings are derived or assumed, not
taken from datasheets; check them against the real boards before wiring.
